## Conway's Game Of Life done in Blazor/C#
[<img width="800" height="444" alt="image" src="https://github.com/user-attachments/assets/32c5ae82-79b0-45e8-be61-70daf4f1717b" />](https://lemonspurple.github.io/cellularLife_blazor/)

🍋 [Play it right here in your Browser](https://lemonspurple.github.io/cellularLife_blazor/)

A small personal project that started as a console app gradually developed into a little app that runs in a browser so that I can share it easier with friends. After a while I tweaked the UI based on my observations of people playing with it and also added more functions. There are a few things like an editing tool or possibily functionality to generate a unique link from a pattern so that it can be shared that might be interesting to solve in the future, however, as of now I'm focusing on bringing this project to Unity to learn more about ECS as Blazor/C# introduces a fantastical overhead compared to simply running this in JavaScript. 
You can read more about this project [here](https://lemonspurple.github.io/cellularLife_blazor/info) or [on my blog](https://lemonspurple.github.io/projects/update/2025/10/28/cellular-automata-in-csharp-blazor.html).
